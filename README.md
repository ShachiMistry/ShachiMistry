## Featured Projects

### [LeetShaders — GLSL Coding Challenge Platform](https://github.com/ShachiMistry/LeetShaders)

A browser-based shader coding platform developed with a team as a CMPE final project. It combines a live GLSL editor and WebGL2 preview with a two-stage judge that uses pixel-level Mean Absolute Error scoring and AI review for borderline submissions.

**Tech:** TypeScript, React, WebGL2, Monaco Editor, Supabase  
[Live demo](https://leet-shaders-seven.vercel.app) · [Repository](https://github.com/ShachiMistry/LeetShaders)

### [LayoverOS — AI Travel Assistance Platform](https://github.com/ShachiMistry/LayoverOS)

A team project created for the MongoDB AI Hackathon. LayoverOS uses retrieval-augmented generation, vector and metadata search, and persistent agent state to provide contextual recommendations across 160+ airport amenity records.

**Tech:** Python, FastAPI, LangGraph, MongoDB Atlas Vector Search, Next.js  
[Repository](https://github.com/ShachiMistry/LayoverOS)

### [Scalable Order Processing System](https://github.com/ShachiMistry/scalable-order-processing-system)

A three-service, event-driven backend for order, inventory, and payment workflows. The system demonstrates asynchronous messaging, idempotency, conditional writes, optimistic concurrency control, retries, and failure handling.

**Tech:** Python, FastAPI, AWS SQS, DynamoDB, Docker, GitHub Actions  
[Repository](https://github.com/ShachiMistry/scalable-order-processing-system)

### [Triton Inference Monitor](https://github.com/ShachiMistry/triton-inference-monitor)

A Python benchmarking and telemetry tool for NVIDIA Triton inference workloads. It captures latency percentiles and GPU metrics through NVML and includes a simulation mode for development without CUDA hardware.

**Tech:** Python, NVIDIA Triton, NVML, Pandas, Docker  
[Repository](https://github.com/ShachiMistry/triton-inference-monitor)
