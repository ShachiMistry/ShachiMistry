### Featured Projects 🛠️

*   🚀 **[triton-inference-monitor](https://github.com/ShachiMistry/triton-inference-monitor)** – *ML Performance & Observability*  
    A high-performance GPU inference benchmarking tool for NVIDIA Triton Server. Implemented automated latency profiling (P50/P99) and hardware telemetry utilizing NVML to optimize inference workloads.
    
*   🤖 **[LayoverOS](https://github.com/ShachiMistry/LayoverOS)** – *Autonomous Generative AI Agent*  
    An autonomous, state-persistent recovery agent for stranded travelers. Built using **MongoDB Atlas Vector Search**, **LangGraph**, and **FastAPI**, orchestrating state-routing graphs and semantic filter searches.

*   📊 **[data-platform](https://github.com/ShachiMistry/data-platform)** – *High-Scale Distributed Platform*  
    A fault-tolerant distributed data platform processing **5TB+ daily** with 100+ concurrent jobs. Utilizes **Apache Spark (PySpark)**, **Apache Airflow**, and **FastAPI** deployed as Kubernetes containers.

*   ⚡ **[scalable-order-processing-system](https://github.com/ShachiMistry/scalable-order-processing-system)** – *Cloud-Native Event-Driven Backend*  
    An event-driven backend service demonstrating microservices patterns. Implements distributed idempotency, optimistic locking, and message queue management using **FastAPI**, **AWS SQS**, and **DynamoDB**.

*   📈 **[Stock-Market-ETL-Analytics-Platform](https://github.com/ShachiMistry/Stock-Market-ETL-Analytics-Platform)** – *Real-Time Data Ingestion*  
    An end-to-end streaming and analytics ETL platform. Architected real-time ingestion pipelines with data validation using **Apache Kafka**, **Apache Airflow**, **Apache Spark**, and **Cassandra**.

*   🎬 **[Netflix_popularity_Predicition](https://github.com/ShachiMistry/Netflix_popularity_Predicition)** – *Machine Learning Engineering*  
    A predictive analytics model trained on historical Netflix content datasets. Optimizes popularity and rating predictions using advanced feature engineering and scikit-learn models.
