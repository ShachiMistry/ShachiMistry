## 🚀 Featured Projects

### 🎨 [LeetShaders — GLSL Coding Challenge Platform](https://github.com/ShachiMistry/LeetShaders)

> A browser-native coding platform where developers solve visual shader challenges and receive automated feedback.

Developed with a team as a CMPE final project. LeetShaders combines a live GLSL editor and WebGL2 preview with a two-stage judge using pixel-level Mean Absolute Error scoring and AI review for borderline submissions.

### ✈️ [LayoverOS — AI Travel Assistance Platform](https://github.com/ShachiMistry/LayoverOS)

> A context-aware travel assistant that turns fragmented airport information into useful recommendations.

Created with a team for the **MongoDB AI Hackathon**. LayoverOS uses retrieval-augmented generation, vector and metadata search, and persistent agent state across 160+ airport amenity records.

### ⚙️ [Scalable Order Processing System](https://github.com/ShachiMistry/scalable-order-processing-system)

The three-service system demonstrates asynchronous messaging, idempotency, conditional writes, optimistic concurrency control, retries, and failure handling.
